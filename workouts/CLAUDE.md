# Zwift workouts

ZWO conventions are split across two skills:

- `zwo-format` — ZWO XML format rules (universal to any Zwift project). Comes from the `zwift-workout-skills` plugin (github.com/tomjelen/zwift-workout-skills), not this repo — see the root `CLAUDE.md`.
- `.claude/skills/high-torque-zwo/SKILL.md` — High Torque Training project conventions.

Both auto-load when editing `.zwo` files.
